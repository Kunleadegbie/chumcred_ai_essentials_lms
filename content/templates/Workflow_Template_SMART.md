Use this to design workflows that save time and can be repeated weekly.

---

## ✅ SMART Workflow Model

**S — Scan**  
Identify repetitive work you do often.

**M — Model**  
Write a strong prompt that handles the work.

**A — Automate**  
Decide the steps and tools:
- ChatGPT only, or  
- ChatGPT + Google Sheets/Docs/Notion/Trello

**R — Review**  
Check output quality:
- accuracy  
- completeness  
- correct format  
- tone

**T — Transform**  
Improve prompt and save as your reusable template.
