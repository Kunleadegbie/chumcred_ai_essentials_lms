# TEMPLATE — Prompt Template (CITSK+)
Use this template to get consistent, high-quality AI outputs.

---

## ✅ Prompt Layers
AI reads prompts in layers:
**Context → Intent → Tone → Structure → Keywords**

---

## 📌 Copy-and-Use Prompt Template

**Context:**  
(Background and situation. What is happening? Who is involved?)

**Intent:**  
(Exactly what you want AI to do)

**Tone:**  
(Formal / friendly / simple / expert)

**Structure:**  
(Bullets / table / step-by-step / checklist / template)

**Keywords:**  
(Specific words that guide accuracy and relevance)

**Constraints (optional):**  
- word count  
- include/exclude  
- format requirements  
- audience type  
- timeline

**Recap request (mandatory for clarity):**  
**“Please recap what you understood before answering.”**

---

## Example (Short)
Context: I have a meeting with a supplier about delayed deliveries.  
Intent: Write a short WhatsApp message requesting update + new delivery date + prevention plan.  
Tone: Professional, calm.  
Structure: 3–5 lines.  
Keywords: delivery update, new date, prevent future delay.  
Recap: Please recap.
