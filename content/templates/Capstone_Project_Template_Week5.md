# TEMPLATE — Week 5 Capstone Project Template
Use this for “My Real-World AI Solution”.

---

## 📌 Project Structure (Copy-and-Fill)

### 1) Project Title
(Example: Customer Support Bot for Mini-Mart)

### 2) Track
Business / Data / Education / Career

### 3) Problem Description
- What problem exists?
- Who is affected?
- Why does it matter?

### 4) Solution Overview
- What AI solution did you build?
- What will it help people do?

### 5) Workflow Diagram (Text or Image)
Write the flow:
Input → Prompt → Processing → Output → Review → Final Delivery

### 6) Prompts Used
Include:
- Master prompt
- User prompt examples
- Output format rules

### 7) Outputs (Evidence)
Add screenshots or sample outputs.

### 8) Business Impact + KPIs
Show measurable impact:
- time saved
- response speed
- reduced errors
- increased sales/engagement

### 9) Limitations + Next Steps
What does it not do yet?
What will you improve next?

### 10) Final Summary
One paragraph explaining why this project is valuable.
